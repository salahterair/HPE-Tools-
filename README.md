#  Tools for Health Profession Educators

A collection of interactive HTML-based medical education resources developed for health profession educators and postgraduate medical education programs.

**Developed by:** Dr. Salaheldin Terair  
**Discipline:** Medical Education | Anatomy | Histology | Embryology

---

## Contents

### 1. Curriculum Development
`Curriculum Development.html`  
A guided resource supporting the design and development of medical curricula, including outcome-based education frameworks and course planning tools.

### 2. Curriculum Analysis
`Curriculum Analysis.html`  
An interactive tool for analysing medical curriculum structure, alignment, and content mapping across learning outcomes.

### 3. Exam Blueprint
`exam-blueprint-2.html`  
An interactive exam blueprinting tool for constructing assessment plans aligned to curriculum outcomes, covering cognitive levels and topic weightings.

### 4. Item Writing Guidelines
`item-writing-guidelines-2.html`  
A practical reference and interactive guide for writing high-quality single best answer (SBA) MCQs following NBME and AMEE item-writing standards.

---

## How to Use

These are standalone HTML files — no installation or server required.

All tools are mobile-friendly and work offline
